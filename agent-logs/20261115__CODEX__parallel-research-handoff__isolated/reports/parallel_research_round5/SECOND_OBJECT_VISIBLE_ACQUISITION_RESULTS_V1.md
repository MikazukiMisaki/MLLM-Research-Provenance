# 第二件可见且未持有：两阶段恢复配对观察结果 V1

## 主要结果

依[事前协议](SECOND_OBJECT_VISIBLE_ACQUISITION_PROTOCOL_V1.md)完成一次小规模真实模型观察：8 个人工构造的双物体文字情境，每个情境第一件已在目标容器、第二件可见、双手为空。每个情境调用一次诊断／子目标生成，再分别以模型子目标和人工明确子目标进行动作选择。**24 次生成全部完成**，工具退出 0；没有自动重试。

| 测量对象 | 结果 | 边界 |
| --- | ---: | --- |
| 第一阶段格式有效 | 8/8 | 符合两行、词数和无动作 ID 的契约，不等于全部事实已验证。 |
| 第一阶段子目标指向拿第二件 | 8/8 | 研究者逐条按题面核对；其中一条添加了「放入 inventory」，语义仍为拿取。 |
| 模型子目标条件拿第二件 | 8/8 | 没有选择撤销第一件、`look` 或 `inventory`。 |
| 人工子目标条件拿第二件 | 8/8 | 动作映射、状态和诊断与对应模型子目标条件相同。 |
| 两条件均有效的配对中动作变化 | 0/8 | 八对均可比较；模型子目标本身均已指向拿第二件，因此没有错误子目标被修正的案例。 |

两条件各无格式无效、截断、未执行或未知。八个场景的正确编号在 `A000`、`A001`、`A002`、`A003` 中各出现两次。这里报告的是 8 个情境、16 个第二阶段选择，不是 16 个独立任务。

## 诊断核对和解释

八条诊断均指出第二件不在当前 inventory；这与题面明确给出的空 inventory 一致。若诊断进一步使用「阻碍完成」等因果性语言，是否成立仍取决于题目和环境规则；本批未执行环境或证明真实物理状态，不能把整条诊断自动判为完全真实，也不报告真实任务的诊断正确率。

在这些状态明确、第二件可见且拿取命令列为可选项的虚构题面中，模型并未复现既有真实轨迹汇总中被选机会状态下一步均为 `look` 的现象。这表明它在这批简单条件下能够输出拿取第二件的动作；两批材料、机会定义、对象状态和候选集合均不同，**不能**据此断定真实轨迹中的 `look` 由可见性、提示、编号或任何单一因素造成。未访问既有方向 2 窗口包及其输入，也未将两批记录拼成配对。

前一批[第二件已持有的观察](GENERATED_SUBGOAL_HANDOFF_RESULTS_V1.md)同样得到两条件各 8/8 的目标选择；本批改变了对象类型、所处位置、可选命令和目标动作，不能将两批差异或相同结果解释为单独的「持有与否」效应。均为研究者编写、已曝光的便利材料，不是留出评估，也不测真实环境执行、局部事件或最终成功。
