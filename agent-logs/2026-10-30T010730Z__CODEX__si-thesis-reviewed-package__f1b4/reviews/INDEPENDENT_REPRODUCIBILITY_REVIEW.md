## Checker interpretation and operational risk

`check_bytes.py` and `check_lineage.py` perform read-only input hashing but **write their result JSON files** in their own directory. They do not call model/environment components. They are inventory scripts, not fail-closed gates: an ordinary missing file or digest mismatch is recorded as `missing`/`mismatch` or `match: false`, and execution still exits zero. Likewise, a mismatched runtime authorization digest is reported as a boolean, not raised as an error. A consumer must inspect every relevant result and verify the upstream bindings; using the subprocess return code alone as a validation verdict would silently accept a bad inventory. Missing top-level inputs or other exceptions can instead cause a nonzero exit. `check_lineage.py` does not authenticate the runtime binding on its own, so its six-plus-six results need the separate authorization and live-context checks.

The existing matrix itself describes these scripts as byte inventories and does **not** claim that their zero exit code is an execution or scientific clearance. No change to those original scripts or evidence was made.

## Re-execution and remote custody boundaries

Current matching inputs are **necessary, not sufficient**, for a rerun. A complete reconstruction still needs actual training data lineage, interpreter and full dependency trees or lockfiles, system/GPU environment, valid configuration/seeds, model and dataset access and licensing, a new reviewed scope and budget, and actual validation. No runtime, model, tokenizer, environment, retraining or evaluation was run for this review; numerical reproduction is not established.

Remote segment statements in the matrix refer to a **previous, separate** GitHub observation at a named commit. That observation compared local segment-derived Git blob IDs with connector metadata for 12 segments and four small full-byte responses. For 11 large segments, it did not download and recompute SHA256 over full remote bytes; raw individual connector responses were not retained. This review did not independently access or download remote material. It therefore accepts the matrix's stated limitation as appropriately qualified, but does not independently verify the previous remote observation or extend it to another commit.
