# Scientific-control decision: recovery development planning

Status: development planning; no scientific execution release. The single self-authored CLEAN-1 witness completed under scripted actions and does not establish an agent improvement or independence from unknown historical tasks.

The earlier proposal lacks a matched-extra-generation arm and is not ready for registration. A later three-arm draft adds an information-ablation comparison; it is still a candidate, not validated production behavior. A control with matching calls and maximum output lengths does not imply matching actual tokens, FLOPs, latency or semantic information. Status-dependent fallback can itself transmit information even when diagnosis text is withheld. The P0-only contrast and recovery-versus-ablation contrast answer different questions, and must be reported separately. The apparent historical H4 and SFT-P0 backend differences remain explicit, not resolved by calling them the same model.

The frozen parser accepts a whitespace-only diagnosis with an otherwise valid stage-1 string. This was reproduced with synthetic boundaries and independently inspected in source. No assertion is made about its occurrence in old model outputs. Keep existing parser status and historical records unchanged. For any future protocol, propose a separate three-valued nonempty indicator applied identically to both recovery and ablation observations, without modifying the action, prompt, original status or inclusion of a pair. Incomplete or unobservable fields are UNKNOWN; nonempty is not correctness. The exact implementation and logging-failure behavior require independent review; the candidate synthetic boolean is not sufficient proof of this three-valued contract.

The draft requires further independent review: exact prompts, neutral placeholder, invalid-stage handling, model/adapter identity, replay and horizon, operation limits, fail-stop accounting and source grouping. Four constructed groups would support only a development case series; group count, custody, unknown historical overlap, full resource budget and training path remain unproven. Preserve prior costs and report prospective increment separately.
