# Prospective analysis note for the new exposed-DEV cohort

Written before the new cohort is run. The primary descriptive endpoint is task success by 50 completed actions, or earlier success. Only if all 36 planned outcomes are complete, report counts for P0, C-old and C-quarter out of 12; for C-quarter versus each comparator separately, tabulate paired gains, losses, both-success and both-failure and show the raw difference in successes out of 12. Apply the preregistered 2/12 and 1/12 thresholds only as an exploratory resource screen. If any episode is UNKNOWN, preserve the full planned roster and report actual complete/unknown/unstarted without substituting, imputing or calling the screen passed.

For a descriptive statistical diagnostic only, exact two-sided McNemar p-values can be calculated for each pair of treatments using d=gains+losses and p=min(1, 2*sum(comb(d,k), k=0..min(gains,losses))/2**d); when d=0 set p=1. Report both raw p-values and two-comparison Holm-adjusted values, with assumptions and no confirmatory claim. These are not the planned resource screen, do not establish stable generalization, and do not correct for this development cohort's prior exposure, adaptation after an observed stop, family dependence, or single training seed. A future independent confirmation needs separately sourced parent tasks and its own prospective statistical design and complete budget.
