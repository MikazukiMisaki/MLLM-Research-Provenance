# 论文开发性观察：中性子目标与必要回退

为避免把“取回已放好的第一件”一概视为错误，我们在第二阶段动作选择提示下构造八个虚构状态，覆盖普通进展、清洗和障碍导致的必要取回、已持有、目标已完成及物体位置未知。每个状态固定任务描述、诊断、动作映射和可接受动作集合，仅替换即时子目标：明确指定相容动作、明确指定局部冲突动作，或使用不指定具体动作的宽泛任务指令。共完成 24 次贪心生成。相容和中性条件各有 8/8 次选择落入研究者事先定义的可接受集合；冲突条件 8/8 次选择被指定的局部冲突动作。中性和相容条件的输出在两个状态下不同，但均属于事前允许的动作。

在这些人工题面和执行给定子目标的接口下，输出对明确的动作型子目标敏感；中性指令条件则在这些题面中产生了被研究者判为可接受的选择。该结果不等于模型自主检测到子目标错误：实验并未向中性条件提供错误子目标，中性指令与具体动作指令的信息量也不同。八个题面只有六套结构，标注者与设计者相同；没有真实状态转移、自然生成错误、留出评估或最终任务结果。因此本观察只作为后续机制与真实记录研究的开发依据，不能解释主线训练产物的成功率变化。
