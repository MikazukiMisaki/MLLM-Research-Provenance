# SI-U1 next-step feasibility evidence package

Status: read-only evidence; not an experiment authorization, task-selection schedule, runnable gate, or held-out certification. This package is restricted to the private research provenance repository because it contains task identity metadata. No model, CUDA, or environment was run to create it.

The archive includes the raw two-policy metadata scans and append-only correction; resource and evaluator static evidence; independent metadata recount; power sensitivity calculations, tests and independent reviews; the final feasibility decision and independent acceptance. The original files are copied into the archive byte for byte, with full source paths, SHA-256 hashes and sizes in `PUBLICATION_MANIFEST_V2.json`. The dataset content files, scientific checkpoint weights, and private credentials are not included.

`build_bundle_v2.py` verifies source hashes before/after copying, every decompressed member byte, and the two independently frozen final-report hashes. A limited credential-pattern scan reported zero matches. The detached source inventory is the publication manifest; `FILE_HASHES.sha256` verifies the package files. The initial non-published local bundle is intentionally not part of this final package.

The dataset isolation is operational and history-limited. In particular, prior proposals are reservations and do not establish that all their contents were unused or used; the append-only correction explicitly records that the 82 SI-U1 evaluation tasks later ran. No new scientific data were collected.
