# Independent review of fabricated parent graph prototype

Decision: **synthetic proof-of-concept only; not ready to process actual or protected tasks.** The candidate supplies a bounded-shape, typed directed multigraph isomorphism comparison and declared-ancestry comparison. A match means equivalence under its supplied encoding; a mismatch or disjoint declared ancestry explicitly leaves semantic and statistical independence UNKNOWN. Missing records, cycles and search exhaustion are not silently converted to independence. This is the correct direction for a task-supply feasibility design, not evidence that new independent tasks exist.

The independently re-run test suite returned 13 passed using the project interpreter. Inspection confirms matching examines edge labels, direction, self-loops and parallel-edge multiplicity; the caller supplies the graph labels and completeness assertions. The recorded source SHA-256 is `7a8da1d12839b699851ade9dbae4736bf5ad70eae823aa1270f4501189221ec5`; tests SHA-256 is `8742312e517b479c453ce73dc35f199b12ef64c33b87ff66ff4fe40b6dceca28`. Testing uses invented graphs only, not real tasks or a protected inventory.

Before any real or protected integration, require a versioned, reviewed construction from actual task semantics; authenticated and independently administered custody; frozen overlap rules; and controls preventing sensitive output or membership queries. A label or submitted graph can omit causal structure, and complete ancestry is merely caller-asserted. Lack of a graph match does not prove semantic novelty. Search limits count candidate assignments or closure-stack pops; they do not bound all CPU work, input materialization, ancestor-edge pushes, memory or wall time. In particular each permitted lineage record may contain many parents, so a large submitted inventory can cause work well beyond the pop count. Use global edge/input ceilings, execution resource limits and UNKNOWN on timeout before accepting untrusted or large data. The code is an in-memory fixture without an input or trusted custody boundary. There is no claim of formal equivalence to environment behavior, comprehensive historical inventory or statistically independent sampling.

This review did not open real or protected tasks, run the model or construct the environment. It grants no permission to use the prototype on a holdout or to run an experiment.
