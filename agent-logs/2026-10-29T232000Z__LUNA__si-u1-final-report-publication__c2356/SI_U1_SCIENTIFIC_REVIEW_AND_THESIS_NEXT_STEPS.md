# SI-U1 科学结果、论文定位与下一步

状态：已完成固定样本评估、完整离线审计和独立统计复算；下一阶段仅为研究设计，未授权或启动新实验。

## 研究问题与设计

问题：在 Qwen3-8B 和相同专家 SFT 起点 P0 上，使用智能体自身成功轨迹继续监督微调，能否提高任务终局成功率，且是否优于使用专家经验续训？

- A：固定 P0；B：从同一 P0 使用专家轨迹续训；C：从同一 P0 使用自身成功轨迹续训。
- B/C 各 78 个训练父任务、312 个不同训练样本、4 遍、1,248 个微批次、78 次优化更新及 6,240 个监督 token。两臂来源及训练任务/状态不同；输入 token 分别为 661,620 与 695,872，C 多 5.18%。相同监督剂量不是相同数据分布或完全相同计算量。
- 82 个评估任务来自互异父目录，三臂使用相同任务顺序与对应环境 seed、每组各运行一次，合计 246 条。冻结的主要比较是 C−A 与 C−B；每组均使用固定最终 checkpoint。

## 独立验收结果

| 模型 | 成功 | 成功率 |
|---|---:|---:|
| A 原始 P0 | 65/82 | 79.27% |
| B 专家经验续训 | 68/82 | 82.93% |
| C 自身成功经验续训 | 67/82 | 81.71% |

| 配对比较 | C 赢 / C 输 / 同结果 | 成功率差 | 双侧精确 McNemar p | 两项 Holm 校正 p | 保守同时 95% 区间 |
|---|---:|---:|---:|---:|---:|
| C−A | 3 / 1 / 78 | +2.44 个百分点 | 0.625 | 1.00 | −7.98 至 +12.42 个百分点 |
| C−B | 3 / 4 / 75 | −1.22 个百分点 | 1.00 | 1.00 | −13.78 至 +11.54 个百分点 |

区间由四个 98.75% Clopper–Pearson 边际区间构造，控制两个比较的同时覆盖；对总体作推断需要抽样或可交换性假设，本轮固定任务并非随机总体样本。两项比较未满足预先冻结的大效应信号；没有触发预定义的观察性退化警报。正式结论是 **INCONCLUSIVE（无法判定）**。该结果不能证明 C 优于任一对照，也不能证明没有效果、等效或伤害小于 5 个百分点。

实际评估监督退出码 0；生产完整审计为 `AUDIT_PASS_LIVE`、246 条、无待处理记录，评估 5,001 次生成、5,247 次含 reset 的环境操作，设备占用 4,263.28 秒。B/C 训练与本次评估共 6,063.34 设备秒（约 1.684 小时）；工程探针 455.86 秒单独记账。独立审查和统计复算均与正式输出一致。

## 已完成的失败与数据只读诊断

在所有 9 个有 C−A 或 C−B 成败分歧的任务以及全部 8 个双物体任务上，共检查 17 个任务、51 条三臂轨迹。37 条失败轨迹均记录到第 50 步终止且 reward=0，14 条成功；2,206 次生成在该子集中均可按当时映射解析并对应执行动作。8 个双物体任务三臂均为 0/8。11 个结果不同的配对比较在首次出现不同执行命令时，所记录的模型输入、观察和动作映射内容哈希一致。

这些是结果选定子集的描述，不是新检验：不能把首次动作差异认定为失败原因，不能证明隐藏环境状态一致，也不能仅凭此断言存在错误的动作解析。重复命令块在失败轨迹中出现，但成功轨迹通常更短，存在检测机会差异；不能直接声称循环导致失败。每臂双物体类别仅有 2 个训练父任务、8 个唯一示例；覆盖有限是待检验假说，不证明它造成了 0/8。原始逐案表含私人任务标识和片段，应保留在私有档案。

## 科学判断与论文可写的贡献

建议继续推进论文和有限的离线机制诊断，**暂不直接扩大相同配方的训练或评估规模**。现有样本里 C 相对 A 净增 2 个成功、相对 B 净减 1 个；数据尚不足以支持成本更高的同配方扩跑，也不足以排除有价值的较小增益或伤害。

论文主线可表述为「固定专家起点下，受控比较自身成功经验与专家经验的续训对 agent 成功率的影响，以及恢复干预的获益和风险」。可以贡献：可复现的三臂配对比较、相同监督剂量下的数据来源对照、逐案失败诊断和对证据边界的诚实量化。不能声称发明了全新自我训练算法、已证明自主改进、或已分离出数据来源的单一因果机制；创新性及相关工作仍需文献对照和导师判断。

R19 的事后 oracle 32/36 与最佳固定 K 的 30/36 相差 2/36（5.56 个百分点），是该固定样本中利用未来结果选 K 的上包络，不是可部署的成功率提升；R19 和 SI-U1 的分母、处理均不同，不能直接相减或合并。R19 可作为恢复过程和风险分析的支撑，而不能作为 SI-U1 有效性的直接证明。

## 关键限制

1. 评估任务来自 TRAIN 分区，仅对已核对的任务、父目录和原始字节证明身份隔离；历史使用记录并不完整，不能称严格 held-out 或证明未见场景/语义。已选任务中 40 个父目录还包含 49 条未运行 reserve 试次；这些试次不可称为来自独立新父任务。
2. 每个续训练臂只有一个训练 seed、一个 checkpoint，无法估计训练随机性；类别样本特别是双物体 8、加热 5 均很小，家族比较仅描述性。
3. 已冻结统计计划原绑定旧版提取器。该版本在评估后离线提取时因 tokenizer 符号链接接口不一致失败；其为快照校验已读取结果文件字节做哈希，但未进入完整结果解析与统计。修复版经过独立审查和事后技术补充后产生本报告；原分析计划、阈值、数据、失败收据均未改写。无法证明其他人或进程此前从未接触结果。
4. 执行者记录原始私有评估归档已上传，并报告其中 11 个大分片的远端 Git blob 身份一致；受连接器限制，未能完整下载正文逐字节复核。最初逐项检查的连接器原始输出未单独留存，不能将事后转录视为独立原始证据，也不能称已完成远端全文复验。

## 下一阶段最小方案：先可行性，再决定是否运行

**第一步：只读准备。** 全部 9 个分歧任务和 8 个双物体任务的逐案审计与训练覆盖审计已完成第二人复核。基于可观察证据提出一个事前可检验的机制假说，例如双物体状态覆盖是否不足；不得把本轮结果选出的任务用于事后调参并再当成测试集。

**第二步：核实独立任务及统计可行性。** 在不看未来候选任务结果的情况下，审查 ALFWorld 现有 split 的历史接触、父目录和 game/trajectory 字节，以及可证明的场景边界；如果隔离不能证明，只能按实际范围命名，不能冒称 held-out。事先固定主要比较 C−A、C−B、任务配对、显著性校正、成功指标和如何处理缺失；基于事先声明的效应、配对分歧率、两比较相关性和家族警报规则计算联合功效或区间精度。不得把单项 McNemar 检验的 80% 功效当作整套决策规则的 80% 功效；当真实效应恰在 10 个百分点门槛附近时，要求观测点估计≥10 个百分点本身就会显著限制通过概率。

**第三步：仅在资源和科学价值足够时实施。** 具体建议是 A 固定 P0，B/C 沿固定配方各使用 3 个预先指定训练随机种子（如协议允许、且完整验收通过，可复用本次 seed），在新的独立任务上按相同顺序配对，且每个任务在各臂使用相同环境 seed。将同一任务上多个训练种子的结果作为相关观测，预注册任务聚合或层级分析，不能当作独立样本；针对多种子结果须预先确定适用的模型和检验，不能直接沿用本轮单个二元配对的 McNemar 检验。使用单一 ALFWorld 环境，禁止事后筛选任务、补缺、选最佳 checkpoint 或自动重试。若 N 个新任务由 A 评一次、B/C 各 3 个种子评一次，H50 的预算上界为 350N 次生成和 357N 次含 reset 环境操作，另加新增训练和工程成本；例如 N=82 上限分别为 28,700 与 29,274，规模示例并不代表有足够功效。

**启动前验收与停止：** 没有可信独立数据来源、事先确定的精度/联合功效、完整任务与物理成本上限、模型/环境一致性或独立审查时，不启动。运行中身份漂移、预算超限、未完成/NA、证据链不完整或中断即停止并保存物理成本，不重试或事后补样本。若先验可行性无法满足，在现有证据基础上完成实证论文，与导师明确贡献和局限，而不是通过改阈值或把 TRAIN 描述为 held-out 追求正结果。
