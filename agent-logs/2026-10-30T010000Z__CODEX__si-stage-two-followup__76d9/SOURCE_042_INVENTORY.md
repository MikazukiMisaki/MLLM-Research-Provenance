## Byte and split comparison

`archive_042_audit.py` independently streamed all three obtained official archives. All archive member names were required to have exactly five safe path components with the expected root and filename, with duplicate names rejected. All three archive file hashes were checked at start and end. Each ZIP member was read to SHA256 without parsing or emitting its content. Local 4,027 game files were hashed for comparison; these dynamic local files were not individually rehashed afterwards. No task IDs are in the aggregate output.

- 0.4.2 and 0.4.0: 4,027 shared paths, 0 new, 0 removed; 3,693 identical game bytes, 334 changed. All 334 changes are in valid_train (200/200) and valid_unseen (134/134); train (3,553) and valid_seen (140) all match byte-for-byte.
- 0.4.2 and installed local games: likewise 4,027 shared paths, no new or removed paths, and the same 3,693/334 byte split; current local files equal 0.4.0 in the previous audit.
- 0.2.2 versus 0.4.2: 4,027 shared paths, all 4,027 with different bytes; 1,207 0.2.2-only paths.
- Identical path/bytes cannot guarantee original provenance or execution history. Different bytes alone do not establish a difference in the public action interface, dynamics, outcome or scientific treatment.

## Conservative scene-label join

`changed_scene_inventory.py` reruns the preserved earlier audit, including protected recorded history, the SFT candidate lists, old reservation, parent and game/trajectory hash exclusions, then additionally excludes version-0.4.2 game hashes of protected parents. Unlike an old-only input, changed-version games have the same path as an existing installed game; the script intentionally permits that and labels them *variants*, not new tasks. On the 334 changed archive paths, the conservative metadata filter leaves **17 existing-path variants / 6 parent names**, all in valid_unseen; their parent suffixes span **2 scene-number labels** and all six labels match the separately recorded G1 suffix set. This exactly mirrors the prior six-parent/17-trial installed inventory. It does not add to the 350-parent old/local union. The count is not an eligible sample, runtime validation, or a claim about same geometry/model exposure; dynamically discovered protected bytes have no separate post-read per-file snapshot.

Full reproducible code, raw API metadata, exact official source snapshots and aggregate JSON are retained here; `OFFICIAL_SOURCES.json` binds master commit and source-file hashes. The separate source-name proxy audit validated suffix against 1,410 recorded historical scene fields, and the official README explicitly names the final field sceneNum; candidate bodies are intentionally uninspected.

## Decision boundary

Do not install/overwrite the new archive, treat its changed byte variants as independent tasks, claim a new unseen scene pool or execute evaluation. Unknown asset licensing, historic/model exposure, differences in old/new observations or transition semantics, compatible reference conditions and adequate statistical precision remain unresolved. An independent checker is recounting archive paths/bytes. Any later decision to inspect behavior needs separately reviewed scope, provenance and resource accounting; this read-only observation authorizes no runtime action.
