## Explicitly unimplemented

The parent is not wired to real production worker, actor, materialization, prior roster/manifest, first-reset snapshot, native success predicate or scientific outcome. This is not the existing `stage_budget` implementation and does not replicate its nonblocking ACK scheduler, two-second ACK deadline, complete EVAL lifecycle checks, process supervisor, subreaper, signal/descendant cleanup, GPU admission/ownership, tokenizer/model/config binding, research wall/token limits, actual per-arm operation budgets or four-pair global scientific ledger. It checks a child-generated receipt and journal, not physical effects or trusted process identity. Same-UID races, symlinks/TOCTOU, and full concurrency guarantees are not solved. A failure during parent log/fsync can leave physical journal contents and memory counters divergent; stop and reconcile offline rather than infer zero or retry. Prior synthetic v3/v4 pair prototypes remain separate and are not integrated here.

This code has no right to launch a scientific experiment. Exact code and evidence hashes are listed in `FILE_HASHES.sha256`.
