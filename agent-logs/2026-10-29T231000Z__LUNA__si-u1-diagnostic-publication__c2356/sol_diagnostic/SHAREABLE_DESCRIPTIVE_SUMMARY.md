# SI-U1 配对分歧与弱类别：只读描述性诊断

状态：单人实证诊断，待 Astra 独立复核；不是新的统计检验或因果结论。任务标识、原始动作/观察片段和逐步事件索引保留在私有表中，不出现在本摘要。

## 范围与证据

从已认证的 82 个任务中完整选择：C−A 的 4 个胜负任务、C−B 的 7 个胜负任务；两比较重叠 2 个，因此为 9 个不同分歧任务。另纳入全部 8 个 pick-two 任务；它们与前述 9 个不重叠，合计 **17 个任务 × 三臂 = 51 条轨迹**。这是按结果选定的子集，不能作为 82 个任务整体发生率或泛化能力的估计。

真实 246 条报告与正式提取的 82 对记录逐项核对身份/结果，所选轨迹从已认证原始事件账本依 arm/task/index 重建并关联 event sequence/ID。报告和事件账本的提取前后 SHA256 与已认证提取一致。实际原始推理/环境、模型和训练均未重跑。前瞻规范的正式结论仍为 INCONCLUSIVE。

## 可观察结果

| 所选子集 | A | B | C |
|---|---:|---:|---:|
| 成功终止轨迹 | 3/17 | 6/17 | 5/17 |
| 失败终止轨迹 | 14/17 | 11/17 | 12/17 |
| 失败轨迹中：50 步后记录 done=true、reward=0 | 14/14 | 11/11 | 12/12 |

全部 51 条轨迹、共 **2,206 次 generation** 的原始输出，经当前动作映射和冻结规则重建均为可选中动作，并与实际 step 请求中的 action ID、命令和动作映射一致；没有在这些轨迹中发现动作格式/超范围解析失败、token cap 或不完整输出。该结论只覆盖所选子集，不证明动作选择正确或全任务没有解析问题。所有失败发生在记录中的第 50 步终止且 reward=0；不据此断言具体环境或策略因果。

全部 8 个 pick-two 任务的 24 条 A/B/C 轨迹均为 50 步、done=true、reward=0；每条均记录 50 个成功解析并执行的动作。它支持“这些选定任务没有由格式解析失败提前终止”，不证明环境不可完成、特定策略步骤错误或训练数据不足是失败原因。

11 个结果不同的配对比较涉及 9 个不同任务（同一任务可计入两个比较）。在每个比较中，第一次记录到不同执行命令的位置，事前可见 prompt、渲染 prompt、input IDs 和 attention mask 的各自内容哈希均一致；当时的 observation 和 action map 哈希也一致。该现象说明记录中同输入下出现不同输出动作，不证明这一差异导致最终成败，也不证明所有未记录的环境内部状态相同。

有一个描述性的重复序列指标：相邻重复的完全相同命令块，块长 2、3 或 4，至少连续出现两次。A/B/C 失败轨迹中分别为 11/14、5/11、11/12；所选成功轨迹均为 0/3、0/6、0/5。仅限全部 8 个 pick-two 任务时，分别为 6/8、5/8、7/8。**不要把它解释成循环致错：失败轨迹都长 50 步，成功轨迹较短，检测机会明显不同；重复也可能是合法动作。** 该指标未与长度匹配对照，也未作盲态/双人语义评定。连续相同步骤的 observation 与 action map 在此样本均未出现；这并不排除周期大于一步、语义相近状态或其他潜在循环。

## 训练覆盖与质量能说明什么

独立只读训练数据审核显示，B（专家演示）和 C（自身成功轨迹）各有 78 个不同训练父任务、312 条唯一示例、四遍各 1,248 次展示、6,240 个监督 token 与 78 次更新；两个臂的 pick-two 都只有 **2 个父任务、8 个不同示例**，四遍后的 32 次展示不是 32 个独立样本。两臂的任务父目录和精确 prompt hash 未重合；每臂内部未发现相同 prompt 的重复或相互冲突标签，动作 ID 格式检查通过。这些是结构/一致性检查，不代表选中动作最优，或数据覆盖足够广。

C 的输入 token 为 695,872，B 为 661,620，相差 34,252（C 多约 5.18%）；相同监督剂量不等于完全相同输入或计算成本。C 选择自身成功 P0 轨迹中的动作，B 使用匹配家族与剂量但来自不同任务的专家示例；任务与状态分布随来源同时变化，无法单凭比较将差异归因于“自我经验”本身。训练覆盖较薄是可检验的后续假说，现有记录**不能确定或排除**它造成 pick-two 失败。先前 tokenizer 长度可行性结果是旧 CPU 结构检查，并非本次重新 tokenize 或动作质量检验。
