The forced-timeout unit case uses a wait proxy on a cooperative child; the test subsequently waits on the same owned Popen, with no signal; it is not a proof that an uncooperative process will exit.
- Known-identity cleanup only operates on the verified owned direct child; process identities, namespace visibility, and host-side GPU ownership have limits. Unknown, nonzero exit or timeout never establishes cleanup success and does not refund prior reservations; no resume or retry is provided.
