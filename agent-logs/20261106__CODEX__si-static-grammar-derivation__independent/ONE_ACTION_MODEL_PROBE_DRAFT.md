# One-action own-task model probe: design draft

Status `DRAFT_NOT_RUN`. Purpose: establish whether the frozen SFT-P0 agent can receive a real observation and return one usable action on the already self-authored engineering task. This is not an efficacy, training or independent evaluation experiment. A failed, invalid or ungrounded output is an observed engineering outcome, not permission to retry or tune on it. The previously completed scripted five-step run is separate and does not provide a model outcome.

## Inputs and decision

Use only the explicitly authored `s1-d1-n0` problem, frozen manual, public domain, derived grammar and reviewed source/runtime. The problem SHA256 is `573f05e8038f38f67a78367585ebdfc80dd65645aafb46865e388bd199790a62`, manual SHA256 `0190fe1247202b24a224cf741a1baccfa093077b89119d8fdf38e690b61efda5`, public domain SHA256 `f1473041ed01da514de1f87adfd7ef0804862361f83ccf63c75e43633b0eb280`, derived grammar SHA256 `dc4929442f919b4a02b5237ced8438e7afe74a0b1e724014b9c0a39a27adac5f`. The derived grammar parsed successfully in isolation; actual reset/intro and state still require validation. Bind and independently verify exact P0 base model, tokenizer, LoRA adapter, Python/package versions, production policy source and decoding before any execution. A local-only runtime configuration must identify those inputs; the original task pools and standard scanning factory are not inputs.

Construct and load direct `PddlEnv` with the three pinned in-memory strings, then reset once. Verify the literal goal in actual initial public feedback equals the manually declared goal and `won` is false. Build one real `ActionRequest` with this observation, empty history and the current public admissible actions. The manually declared goal supplies `Task.text`; neither hidden facts nor groundings enter the prompt. Use the existing SFT-P0 policy with greedy decoding and the frozen P0 adapter. The draft ceiling is one generation with at most 64 new tokens; a 4,096-token input ceiling is a proposed engineering guard, not an established property of the original P0. Count the exact rendered chat-template tokens before generation and stop if this guard would be exceeded rather than truncating or changing the prompt. Confirm that any pre-count matches the tensor consumed by the actual policy; otherwise no token-cap claim is justified.

Record raw model output, token counts, prompt and action mapping hashes, parser result, device observations and source/runtime/input bindings. A valid parsed action is eligible for one step only if its exact public command has exactly one corresponding entry in the full non-deduplicated environment mapping. Record the chosen grounded action and before/after relevant facts. Invalid parser output, missing or ambiguous grounding, unexpected observation, input drift or resource/monitor uncertainty stops without a step and without retry. Do not replace the model selection with the scripted command. One step is not an episode success-rate result.

## Bounded accounting and prerequisites

Maximum intentional scientific-facing calls for this probe are one environment construct, one load, one reset, one model generation and one environment step. Internal PDDL translations, tokenizer calls, model/adapter loading, temporary native-library copies, failures and cleanup are additional separately recorded operations. The one-step ceiling is not a full future campaign budget. Proposed outer wall-time threshold: 15 minutes, monitored and explicitly soft unless actually enforced; any timeout, monitor loss or unknown external operation stops. Record effective device-wide and process-visible GPU observations and peak memory without presenting unattributable device memory or host PID mappings as owned-process usage. Shared-device admission and model memory requirements need empirical, reproducible checks; an idle snapshot is not a guarantee of capacity. Capture end-to-end input and output token counts and actual timing, including failed starts and unknown costs. Existing SI-E2 `model_load` failure remains open in its original ledger; no historical failure is overwritten.

Before this draft can be executed, implement a distinct default-disabled runner and supervisor, bind the actual argv/environment/source/model/output identities, establish file-access behavior sufficient to respect the prohibition on protected tasks, test interruption/ledger/cleanup and token-cap failure paths with synthetic edges, and have the exact enabled bytes independently reviewed. The existing user authorization to continue research is not a need to ask again; these are technical evidence requirements. No model or environment was run to create this draft. A later positive probe would not validate a common training dataset, C1/C4 training semantics, independent test provenance, statistical precision or a complete research budget.
