# 与主线真实记录的下一步接口

目的：判断在同一批明确可使用的记录中，可以测量哪些阶段；不把人工题面与主线训练结果拼接为因果链。

1. **来源与用途**：与主线负责人确认具体来源、开发用途、采集协议及已有暴露范围。训练使用、开发使用与独立确认是不同属性；可用于开发不自动等于留出。此前明确受限的窗口包及其三份缺少排除证明的输入继续排除，不读取其逐案内容。当前没有确认任务池这一状态不等于所有真实开发记录均不可用。
2. **直接 actor 轨迹**：如果主线记录是直接动作选择、没有阶段一，连接可见目标／观察、动作、下一状态和预算内结果；诊断与子目标标记为 `NOT_COLLECTED`，不能称其自然产生了正确或错误子目标。可描述动作与后续的相关性，不凭不同队列归因。
3. **确有两阶段的同批记录**：只在来源与用途获准且同一次调用实际保存阶段一时，记录事实依据、子目标相容、动作落实、局部结果和终局；不足信息标 `UNKNOWN`，未执行和截尾分开。标签使用当时可见信息，不由未来终局倒推。
4. **最小交付**：按 task/state/condition/call 和来源稳定键统计可链接、缺失、不可判定数；明确任务为主要单位及多臂共享关系。先给出少量开发样例及标注规范，再决定独立双标与更大规模研究；不因没有显著结果追加未冻结实验。
5. **采集时字段**：记录模型实际看到的输入及其 token IDs 或可核查摘要、调用 ID、原始输出、映射、执行回执、可观测后状态、预算内结束、缺失和成本。事后构造摘要不能认证历史调用。

可复用的合成软件原型位于相邻 `trajectory_link_synthetic_v1`；它目前拒绝非合成来源。真实适配器须在确认来源、字段及适用协议后单独实现并记录，不能通过更改 `source_kind` 绕开现有限制。
