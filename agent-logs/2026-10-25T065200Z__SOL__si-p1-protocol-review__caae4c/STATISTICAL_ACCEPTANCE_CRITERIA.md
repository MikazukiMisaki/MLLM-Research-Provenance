# SI-P1 统计验收与停止规则

状态：**审查后的前瞻设计标准；无新实验、N/预算未授权**。这是方法取舍标准，不是已有模型的结果。不从 R19 的 oracle 2/36、11 个训练候选或旧专家 SFT 的提升反推新模型效应。

## 估计量与检验

独立单位为 canonical task/trial，最终清单与分析一次冻结。同一 task 的多个 prefix 不增加 n。三臂在相同 task 集各评估一次；训练、选择、调试用过的 task 与评估隔离。推断仅针对预先定义的 task 抽样空间、这三个冻结 checkpoint；单一训练 seed 不支持跨训练 seed 的稳健性主张。

两项共同主比较为 C−A、C−B_pool。每项完整报告：两者成功、仅 C 成功 W、仅对照成功 L、两者失败，以及 Δ̂=(W−L)/E。gross rescue=W/E，gross harm=L/E；不能只报告 net delta。

主检验采用**双侧 exact conditional McNemar**。D=W+L；D=0 时 p=1，否则

`p = min(1, 2 × sum[j=0..min(W,L)] choose(D,j) / 2^D)`。

两项 p 使用 Holm、family α=.05：按 p 升序，第一个须≤.025、第二个须≤.05；同时要求两项 Δ̂>0。两项的相关性不视为独立。该 exact 方法较保守，预先接受这一代价；结果出来后不切 mid-p、单侧或换主比较。[McNemar 方法比较原文](https://link.springer.com/article/10.1186/1471-2288-13-91)，[逐步检验和 FWER 的研究论文](https://arxiv.org/html/1211.3313)支持这里的检验结构；本文阈值和决策责任属于本项目。

每项另报告 95% **边际** paired-proportion difference 区间，预选 Newcombe 1998 method 10（score intervals 配 paired correlation correction），未来实现需用论文示例独立核对。它是近似 score 区间，不宣称 exact coverage；两个区间不是联合 95%。不使用独立两比例标准误，也不把 discordant wins 的二项区间直接乘 D/E 冒充净差区间。[原始配对比例区间论文](https://www.eiti.uottawa.ca/~nat/Courses/csi5388/Newcombe.1998.pdf)

## 冻结的项目决策门槛

以下数值是协调方在见新结果前提出的**最小继续研究价值标准**，不是用户新批准的预算或对真实效应的估计：

| 条件 | 预设标准 | 可支持的表述 |
|---|---|---|
| 成功率 | 两项 Holm 检验均拒绝且方向为正 | 对这个预设任务空间/冻结 checkpoint 有改善证据 |
| 实际价值 | C 相对 A、B_pool 的观测净增益均至少 5pp | 达到项目观测价值门槛；**不能称真实效应至少 5pp** |
| 副作用 | 两项比较的观测 gross harm 均≤5%，完整披露其不确定性 | 通过本样本的伤害筛查；**不能称总体伤害率≤5%或无伤害** |
| 证据与成本 | 数据隔离、原始收据、配对完成、预设预算全部通过 | 可进入解释，不能用统计显著掩盖证据缺陷 |

5pp 表示约每 20 个 task 多一次净成功，是研究决策阈值，与旧 oracle 的 5.56pp **数值相近不构成依据**。5% gross-harm 是额外观测护栏；它与 net 5pp 是不同量。若要主张总体伤害上界、非劣效或经济最优，必须另设计并控制相应检验，当前不做这些主张。

所有门槛都满足才把本轮学习配方视为值得下一阶段验证。C>A 但未胜 B_pool：只支持普通成功演示/额外微调可能有用，不支持增量采纳的独立价值。C>B_pool 但未胜 A：不能声称提高原 agent 成功率。

## 精度与样本量：当前不能以小池承诺 5pp

独立 stdlib 规划只枚举假设值，不读新任务结果：设真实净效应 δ，真实 discordance q，则 `D~Binomial(E,q)`，`W|D~Binomial(D,(q+δ)/(2q))`。这是同质独立 task 概率模型下的规划假设，不是从历史数据拟合。参考成功率还须落在 `[p_loss,1−p_win]`；高 q 不一定和高基线成功率相容。

同目录 `hypothetical_power_enumeration_v2.json` 保存 112 个场景、整数 exact 截点和独立小 n 多项枚举交叉核对。下表只讨论两项检验的 **p-value 组件**，不含实际价值/伤害/完整性等门槛：

| E，真实 δ=5pp | 假设 q | 单比较正向 p≤.025 概率 | 两项正向 Holm p-value 事件的界 |
|---:|---:|---:|---:|
| 74 | .10 | 9.01% | 0–15.04% |
| 74 | .20 | 6.25% | 0–10.41% |
| 200 | .10 | 42.55% | 0–54.33% |
| 200 | .20 | 20.94% | 0–29.82% |
| 600 | .10 | 95.03% | 90.05%–97.31% |
| 600 | .20 | 66.55% | 33.10%–76.00% |
| 1000 | .20 | 89.43% | 78.86%–93.77% |
| 1141 | .20 | 93.30% | 86.61%–96.26% |

界的计算：两项都有相同 δ/q 时，充分事件“两项均 p≤.025”的 Fréchet 下界为 `max(0,2×power025−1)`；必要事件“两项均 p≤.05”的概率不大于 `power05`。不假定两个比较独立，不把这些界叫实际 joint power。参数不同则用 `max(0,p025A+p025B−1)` 和 `min(p05A,p05B)`。

这些数字**不是完整验收功效**。例如 q=.20、δ=.05 意味着真实 gross harm=.075，本身与5%观测护栏有冲突；即使 p-value 能通过，仍可能无法接受。真实 δ 恰在观测 5pp 门槛时，点估计过门槛的概率也不能当作 1。

表中的 E=74 仅是数学场景；known-use 差集 74 不等于可用 held-out。E=200、600、1000、1141 也不是已选任务数或新拨付。三臂 H50 的最坏评估成本分别是 `150E generations / 153E reset-inclusive operations`，例如 200 为30,000/30,600，1000为150,000/153,000，尚不含训练及独立数据获取。

**当前不批准“先跑小样本，显著就算方法成立”的路线，也不凭这张表指定 E。** 最终 E 必须与任务空间、可接受 δ/q 范围、完整门槛功效和实物预算共同冻结；本轮目标核验与元数据差集不能替代这个决定。如只能承担明显低功效的小 feasibility，应另明示探索性目的和不能得出的结论，不能事后升级为确认性证据。

## 停止规则与结论分层

1. **执行前停止**：同池 B=C、共同质量/来源不可解释、身份交叉、无法闭合独立任务、训练 token/重复上限/成本缺项；标记 NOT_READY，不靠复制训练行补足。
2. **执行中停止**：输入或 SHA 漂移、预算/环境接口异常、缺收据/不完整科学操作、协议外调用。保存原件、真实退出和已花成本，不自动重试/换 task；不把基础设施中断记为任务失败。
3. **只分析一次**：没有按显著性提前停止、选 checkpoint/seed、补一批到显著或选择 family。技术完整性监控可以进行，不监看处理效应后改设计。
4. **完成但未达门槛**：区分低精度的 INCONCLUSIVE、C未优于强基线、未优于同池对照、观测伤害超阈值或成本不可接受。p>.05 不是“无效证明”；也不因此允许第二轮 prompt/epoch/selector 搜索。
5. **论文路线**：若当前历史小池无法形成有意义的独立比较，结束这条学习配方的实验推进，以既有 SFT 主结果、恢复收益/副作用和成本/反例形成实证论文。不能把管线、审计复杂度或 oracle 标签替代 self-improvement 成功率证据。

本标准不改冻结 R19、不追认新执行。所有实际科学计数仍为本轮 0，累计 R19 5,142/7,949 不变。
