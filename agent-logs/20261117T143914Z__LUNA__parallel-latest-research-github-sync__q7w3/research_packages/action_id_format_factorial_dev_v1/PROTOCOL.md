# 动作行样式 × 输出格式：固定开发试验

2026-11-16，首次模型调用前固定。由上一批 16 条格式失败启发，但研究问题、题面、处理和预定解析与之不同；不重跑或改判旧批，不使用其四个有限预算状态。本研究不读取受保护任务或方向 2 受限材料，不重启关闭的 120 状态评分批次，不更改项目冻结 baseline、联合算子或生产 parser，不添加 selector、记忆、环境、训练或多轮恢复。

## 问题与条件

8 个新编虚构单步情境，4 类结构各 2 个词汇变体，每例固定状态、即时子目标、四个动作、编号和行位置，交叉比较：候选行编号 `plain`／`bracket` × 输出指令 `bare`／`bracket`。行样式的唯一文本变化是各动作编号有无方括号；输出条件改变整句格式指令。指定动作编号 A000–A003 各对应 2 例，顺序按情境预设循环，使四条件分别各有两次处在第一、第二、第三和第四位置。总预算 8×4=32 次贪心生成。

每次只提供一条完整的独立用户消息，不携带此前对话；模型在同一进程中连续驻留，时间顺序和运行状态仍可能影响结果。被试明确要求执行给定子目标；题面和候选均为人工编写，不证明真实行动可行或自主规划。8 题并非 8 个独立任务，4 条件重复使用相同状态；样本已经受到上一批结果启发，不是独立确认。

## 预先固定的解析和计数

在模型 EOS 结束后用同一 tokenizer 解码、移除字符串首尾空白，然后：裸编号要求须完整匹配 `A` 和三位数字，方括号要求须完整匹配一对方括号内的同样编号。不能先去括号再判断要求。分别报告：

1. **条件所要求的格式形状**是否满足；若形状满足，再判断编号是否存在该题当前映射。未在映射中的编号记 `id_not_in_mapping`，有多余文本、错误括号等记 `format_mismatch`；二者都不是有效语义动作。截断、已开始但无结果、未开始分别记。
2. **统一裸编号参考**：无论本条件的输出要求，都另外记录是否完整符合裸编号形状以及编号是否在映射中。带括号输出在括号要求下可以正确而不符合裸编号参考，这不是同一生产接口的提升。
3. **语义**：仅在满足本条件格式形状且编号存在映射时报告动作及是否与指定子目标一致；已列但不符子目标仍为有效编号，不算格式失败。按每条件计划 8 题列出有效且符合子目标的联合计数；保留所有无效、截断与缺失。

主要描述为四条件的格式形状数及映射有效数，另在同题、相同输出要求内做行样式配对，完整列双方有效、仅一侧有效、双方无效及缺失。语义动作变化仅对两侧均有有效映射的配对计算，并标明分母；这一按结果筛选的子集不代表全体 8 题。无显著性检验，不测置信度、真实环境动作或任务成功。

## 运行、资源及停止

仅在已授权的 Qwen3-8B 本地开发路径与共享 GPU 可用时，使用已可导入模型依赖的现有 Python 环境运行一次。使用离线加载、BF16、无 thinking、贪心、每次最多 16 新 token、输入最多 1,024 token；保留准备提示、实际输入 IDs/摘要、候选映射、生成 token、解析结果、调用身份、模型配置和 tokenizer 摘要、软件版本、时间及离散设备样本。记录可固定内容但不独立认证模型权重、物理调用或 GPU 独占。

加载前显存须低于 8,192 MiB、利用率低于 5%；加载后及每次调用前后显存须低于 43,008 MiB。采样失败、设备身份不一致、输入或文件超限、异常终止、日志写入问题或单次调用达到 120 秒即停止；CPU 限额 1,800 秒，单日志文件上限 16 MiB，外层墙钟超时 1,800 秒加 30 秒强制结束。单次 120 秒通过进程信号和返回后计时检查；原生操作可能延迟响应，不声称硬实时截止。设备采样是离散观察，不证明独占或峰值。人工、系统 I/O 和其他进程成本未必可测，未知不记零。

使用本研究一次性新输出目录，不覆盖、自动重试、为补足有效输出补跑或换目录继续；任何不完整尝试保留。运行前核验上述固定摘要、解释器与设备状态，并在共享交接说明预计时段；结果无论阳性、阴性或格式失败都如实报告。旧批次和被自动安全审查拒绝的历史评价器／暴露检查均不涉及。
