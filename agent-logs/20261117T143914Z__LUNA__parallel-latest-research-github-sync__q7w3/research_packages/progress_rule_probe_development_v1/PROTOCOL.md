# 进度规则单步探针：固定开发方案

2026-11-16，首次调用前固定。该研究采用四个新编虚构有限步题面、三类基础结构；其中紧／宽预算是同一结构配对。它与此前[未加载模型即停止的 32 次方案](../execution_contract_factorial_dev_v1/RESULTS.md)有不同题面和不同进度规则，不补跑旧方案，也不改写其失败记录。它不使用已关闭的 120 状态评分批次或方向 2 受限输入，不修改冻结 baseline、联合算子，不增加 selector、记忆、环境、多轮恢复或训练。

## 操纵与任务

对每个人工状态，用相同动作映射交叉比较两个契约和两个研究者指定即时子目标，最多 4×4=16 次贪心选择：`follow` 要求选择执行即时子目标的动作；`progress` 将子目标视作建议，要求行动沿任务完成路径推进、尽量不撤销已满足条件，必要时允许回退，并在有可推进动作时不选择既无状态变化又无信息的动作。两种契约的长度、内容和优先级不同，比较的是完整文本处理，不识别单词或模型内部机制。

四个状态分别是 2 步紧预算、相同映射与状态的 4 步宽预算、3 步清洗必要回退、6 步但入口是否阻挡未知。确切题面、规则、动作和调用顺序见 `cases.json`；每个状态两个子目标在同一契约下分别指向不同动作，unknown 中两者都不被事先标为唯一正确。紧／宽的映射一致，其他状态采用固定映射；这是固定设计，不是动作顺序的随机化实验。

独立审阅者 Astra 检查了 V1、V2 的逐题步数与路径；审阅意见和修改见 [记录](SEMANTIC_REVIEW_V1.md)。V3 仅在 V2 的 progress 契约末增加明确排除无信息、无状态变化的保守动作的句子，以处理审阅者指出的宽预算歧义；这个最后的具体句子没有再次独立审阅。题面作者选择的规则及标签不是环境真值或独立盲标。

## 结果与分母

报告每一状态、契约和子目标下的动作，以及配对契约间语义动作是否变化。下面几个维度分别记录，不能合成唯一“正确率”：

- **子目标执行**：选择是否与指定的即时动作一致。follow 条件选择其指定动作即为遵循该契约，不能仅因动作撤销进度称其违约。
- **作者指定进度规则匹配**：前 3 个题面的指定推进动作分别为拿 B、拿 B、拿 A；最后一个状态中回退是否必要未知，因此记 `UNKNOWN`，不纳入此标签的可判断分母。这是对作者指定规则的判断，不是独立金标准。
- **回退／无推进**：按题面列出的状态变化分别记录；清洗题面中取 A 既是回退，又可能是必要行动。`look` 与 `inventory` 不改变物体也不提供新信息。
- **作者根据给定转移与剩余步数判断的可达性**：紧预算只有拿 B 可按题面完成，宽预算四个当前选项均可完成，清洗题面只有拿 A 可完成；最后状态没有足够信息确定回退是否必要，因此本探针不对该状态的输出计可达性分数，而非声称每个动作都没有已知性质。事实上先拿 A 有一条对两种隐藏状态都成功的路径。此为题面模型推演，不是实际执行结果。紧预算的回退使目标预算内不可达，不等同于宽预算中的纯进度偏好。

格式无效、截断、已启动但无结果和未启动分开记录；目标是 16 次、每条件四个相关状态。已给的未知状态保留在总题数中，不因模型输出删改。报告完成数、缺失、逐题输出和成本，不计算显著性，也不推广到新任务、自然错误率、真实任务成功、模型训练收益或独立 held-out。
