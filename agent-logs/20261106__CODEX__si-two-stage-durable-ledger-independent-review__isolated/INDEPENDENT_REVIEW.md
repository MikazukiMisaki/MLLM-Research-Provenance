# Independent exact-byte local fake ledger review

Disposition: FAIL for using the audit's `RETURNED` as authoritative completion/durability under failed terminal fsync; fake software wiring exercised, not authorized for live execution. Review scope is candidate exact bytes in the pinned SHA256SUMS file, checked before and after tests. No candidate source was edited. This review creates no model/environment/GPU execution permission.

## Reproducible finding: completion can be overstated

`local_ledger.py:72-82` writes a complete event before its fsync. `fake_probe.py:184-185` catches an OSError from the terminal event fsync and returns UNKNOWN. `audit_fake.py:72-84` sees the still-readable event and reports RETURNED. The independent `reproduce.py` injects an OSError at `journal_fsync,attempt:ATTEMPT_RETURN`; fake generation ran twice, the owner reports UNKNOWN and its ledger is unhealthy, but audit reports RETURNED. A simulated KeyboardInterrupt at the same location independently reproduces the contradiction: caller interrupted, audit RETURNED. Bytes readable through the page cache do not prove the attempted fsync succeeded. No crash or power loss was simulated, so this demonstrates a false positive at the software interface, not a particular storage crash outcome. For an injected failure at ATTEMPT_UNKNOWN, audit correctly remains UNKNOWN. A claim fsync failure leaves a visible claim and blocks same-directory retry in this test, but visibility is not a guarantee after power loss; there is no independent owner/custody or global exclusion. Same-handle retries were refused in all tested paths.

Required before any use of this audit as a durability/completion authority: define and test a conservative completion contract that does not infer successful durable commit solely from readable terminal bytes, combine with an independently observed completion channel where appropriate, and preserve UNKNOWN when the durability outcome is not established. Test both OSError and interrupt at terminal RETURN, UNKNOWN, and claim boundaries. Any revised design must acknowledge that its own receipt writes have failure windows and that same-account local evidence is not tamper-proof. This is a concrete defect in acceptance semantics, not evidence that any real experiment ran or was lost.
