Status `CPU_TOKENIZER_NORMALIZED_GOAL_ONLY`, independent review pending. This is an additive correction to earlier own-task offline prompt measurements, not a revision of their original files. The original manual's goal ends in a period. The actual production `AlfWorldTextEnvironment._task_from` removes trailing periods from the extracted task text. The earlier four-prompt and real-tokenizer/fake-model checks passed the manual text directly, so those were real prompt-function calls with a different task-text string from the standard extractor's normalized output; they cannot certify byte-identical standard-adapter prompts.
