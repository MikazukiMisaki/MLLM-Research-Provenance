# 错误子目标与动作候选得分：事后探索

**评分前固定；基于已经观察到的四条件动作结果提出，不是留出验证。** 问题：在已曝光的八个虚构双物体状态中，给定错误子目标时，模型对「取回第一件」的规范编号候选是否仍集中高权重？这一观察联系两阶段子目标交接与动作候选得分，不能把得分解释为任务成功率、校准置信度或自然诊断出错率。

## 对象、指标与比较

使用三份既有虚构题面日志的 32 个第二阶段提示：八个状态各有原诊断／原子目标、原诊断／研究者注入错误子目标、注入错误诊断／原子目标、注入错误诊断／错误子目标。原模型生成结果已知，四条件和八状态复用；提示及原始输入 token 从日志提取并检查摘要，模型原始条件和两类注入条件之间分别只改变相应字段。研究者此前已看到这些输出，本次不重复生成、不执行环境动作。

对每条提示，分别教师强制评分四个规范裸编号 `A000`–`A003` 的 tokenizer 序列以及指定 EOS `151645`，取完整序列条件对数概率之和，四候选内 softmax 归一化；共最多 **32×4=128 次前向**。四个编号当前 tokenizer 编码、EOS 和先前输入前缀均需通过核对，任一不匹配停批。原日志中的贪心后缀可能使用另一 token 分段或 EOS；另报规范得分最大项与原已存贪心 ID 的一致数，若不一致保留并解释，不能自动认作计算错误。

预定描述：四条件各计划 8 个提示，分别报告可计算数、错误取回动作的归一化权重中位数及范围、权重超过 0.9 的数量、取回与拿第二件两候选的对数得分差中位数及范围、规范最高分候选与已记录贪心 ID 一致数。固定诊断、按同一情境配对比较注入子目标前后取回权重的变化方向和有效对数；固定子目标则比较注入诊断前后变化方向和有效对数。数值饱和及精度不稳定时，按实际可表示值报告相等并结合对数得分差解释；不做显著性检验。原诊断除第二件不在 inventory 外未全部验证，错误诊断与错误子目标均为人工注入；动作遵循错误子目标不等于第一阶段自然产生了错误。

归一化只覆盖四个具体规范编号序列与单个 EOS，不包括其他回答、其他 EOS 或不同 token 分段；高权重不等于所有可生成序列上的概率、模型对目标正确性的信心、真实环境成功概率或校准置信度。BF16 模型得分及后续浮点归一化的极小差异不保证跨精度稳定。原先已暂停的非基准 TV 端点及半质量界不在本批计算。
