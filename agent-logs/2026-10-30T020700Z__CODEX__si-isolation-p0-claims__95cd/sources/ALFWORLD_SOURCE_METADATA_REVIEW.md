# ALFWorld task-source metadata and historical-exposure review

**Decision: NO SOURCE IN THIS BOUNDED REVIEW IS CERTIFIED INDEPENDENT OR UNEXPOSED.** Official split descriptions and package/version metadata describe origin and intended benchmark partitions; they do not establish this project's full task history or the exact model's pretraining/post-training corpus. This conclusion is about present evidence, not a claim that no suitable source can ever exist. No task IDs, candidate game text, trajectories or result values were read or published in this review. We did not download datasets, task lists, archive members, model weights or run/generate an environment. Public documentation and file/directory metadata were consulted only.

## Model and terms

The [Qwen3 technical report](https://arxiv.org/html/2505.09388) describes broad pretraining data categories but supplies no individual ALFWorld-task non-exposure certificate in the inspected text. The actual historical P0 base/tokenizer revision is not completely established by project receipts. An upstream dataset split, archive upload date, or lack of discovered log entry cannot certify that a Qwen3 model, the project's adapters, or its evaluation processes never encountered a task or semantic equivalent. This does not assert that any particular task was seen.

Both [ALFWorld repository](https://github.com/alfworld/alfworld/blob/aaba6870f86c5be6a08a491f32a50b906227bc3e/LICENSE) and [ALFRED repository](https://github.com/askforalfred/alfred/blob/master/LICENSE) have MIT software license text. That alone is not an authoritative source-specific determination of rights for each separately distributed archive, derivatives, data or benchmark submission. The [ALFWorld archive-terms question](https://github.com/alfworld/alfworld/issues/132) is still open with zero comments in metadata read at the recorded time. It is a question, not a legal ruling, grant or proof of prohibition. Exact terms and intended use require appropriate source-specific confirmation before reuse/redistribution.

## Decision boundary

The existing source records document some actual exposure and a range of possible origins; none establishes a fresh independent cohort or satisfies the independent-source gate. Prior policy protects known use and proposals even when missing individual receipts prevent a positive use finding. A lack of records is not proof of clean history. Distinguish future evidence of project non-use from stronger model-corpus non-exposure claims. Continue only bounded evidence/rights work and thesis development; this metadata lookup neither designs nor authorizes a new evaluation or experiment.

`METADATA_RECEIPT.json` contains release-asset timestamps/names, the issue state and AgentBench directory entry names, without candidate contents. Original release API snapshot SHA `39096d15e106aea81e0d8b9e7cc8bc9c4f1538e31558a0b5b1ef22beecc23b3b`. Prior reports are cited as findings, not newly rerun by this review. The directory timestamp is a namespace label; the receipt contains the actual UTC check time.
