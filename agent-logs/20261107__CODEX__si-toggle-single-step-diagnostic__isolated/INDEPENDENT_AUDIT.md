# Same-domain toggle diagnostic: independent read-only audit

**The one-step development diagnostic returned complete observations.** Its new self-authored case shows a concrete difference between native state and the Python fact mirror after a toggle: native reports the switch on, while the mirror reports `not_ison`. This provides a plausible, directly traceable mechanism for the earlier D mirror discrepancy, but D itself did not retain its native-state/effect-slot observations, so its exact underlying cause is not directly proven. Neither observation is a model success-rate result.

The pinned TextWorld `PddlState.apply` source loops through the returned slots in order, converts each to a proposition, removes its negation, then adds it. That source behavior is consistent with a later negative `ison` slot overriding the earlier positive one in the Python mirror even though the separate native state is positive. The old D raw mirror independently contained `not_ison(lamp_d)` and `istoggled(lamp_d)`, consistent with the same observed pattern. This is a mechanistic inference across cases, not an observed D native trace or proof of a general engine defect. The instrumentation itself wraps native and PDDL calls and adds observations, so observation effects and timing cannot be ruled out from this single run.
