# Independent ALFWorld 0.4.0 / 0.4.2 game-member recount

Status: INDEPENDENT_BYTE_RECOUNT_MATCH; BEHAVIORAL_COMPATIBILITY_UNPROVEN. `archive_compare.py` is a separate implementation from the first recount. Run it with `python archive_compare.py` in this directory. It inventories every non-directory ZIP member, requires every `game.tw-pddl` path to have five expected components and rejects duplicate names, streams each game member through SHA256, separately streams the current local `game.tw-pddl` files, compares path/hash sets and writes only aggregated counts and input hashes. No archive was extracted and no task content was parsed or emitted. No model, CUDA, ALFWorld or other environment was run. The ZIP objects themselves were rehashed before and after this audit; local game file hashes were each obtained during the scan, and local file stability across the scan was not separately checked.

Both ZIPs contain 4,027 non-directory members, all `game.tw-pddl`; the member paths are exactly the same. For 3,693 paths the bytes match; for 334 they differ. All changed paths are in `valid_train` (200 of 200) and `valid_unseen` (134 of 134); all common `train` (3,553) and `valid_seen` (140) members are byte-identical. The current local scan found 4,027 games; paths and SHA256s match all 4,027 members of the 0.4.0 ZIP and 3,693 of the 0.4.2 ZIP. The scan did not compare local trajectory, config, grammar, package files or environment observations. It does not prove when the 0.4.0 asset was installed.
