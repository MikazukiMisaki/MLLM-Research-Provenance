# 自我改进研究：现有证据、论文价值和下一步

## 现有结果

- 已完成的一次前瞻性三臂开发对照使用同一批 12 个已暴露 TRAIN DEV 父任务、三臂均完成 36 个回合。P0、原有 C 和低学习率 C 均为 10/12 成功、2/12 在 50 步内未成功；两组配对比较均 gain=0、loss=0、净差 0 个百分点。原先的 +2/12 与 +1/12 探索筛选没有通过，因此不继续同一低学习率小样本路线。此前因接口停止的第一批依然是 UNKNOWN，不计入这 12 对。
- 这不是独立确认：任务已暴露，样本小、只有一个续训种子，新批次也在看到先前技术停止后设计。它不能证明三种方法总体等价或自我改进无效。此前 SI-U1 的 P0 65/82、专家 B 68/82、自成功 C 67/82 同样属于已暴露开发观察，差异较小且不稳定性未解决。R19 的 5.56 个百分点是事后 oracle headroom，不是实际可部署的成功率提升。
- 事后行为对照发现，低学习率 C 相对 P0、原 C 各有 10/12 条完整动作序列相同、2/12 在共有步骤出现不同动作；两组不同任务仅交一例。这说明本次终点相同不等于每一步策略完全相同，不能据此推断行为变化原因。

## 失败轨迹能支持什么

两项共同失败的已暴露 DEV 任务中，一项是双物体任务：三臂均处理同一实例，之后出现反复观察或位置往返；日志中没有证据证明另一实例在所记录位置可拾取。另一项需要加热和放置，三臂均反复开关容器，记录的可选命令没有出现目标类型的拾取操作。这些现象支持研究探索与重复行为，但不能仅凭两例认定记忆缺陷、目标不可达、或某个纠正动作一定有效；这些任务已被查看，不可作为未来独立确认样本。

## 对论文的意义

现有结果足以支持清楚描述研究问题、基线、受控比较、真实负结果和局限，也能作为设计下一项自我改进研究的依据；尚不足以宣称自主自我改进稳定提高成功率。论文若以成功率提升为主要结论，还需要来源可追踪且预先划分的任务、父任务隔离、明确的自生成数据与匹配对照、多个训练种子、预先指定的主要指标及足以支撑目标差异的样本与完整预算。创新应体现在清晰的经验获取与训练机制、严格对照和可重复测量；简单调整学习率或把 oracle 结果当可部署方法都不足以单独支撑该结论。

同提示不同标签的备选扫描在自成功 C 数据上得到该严格条件下 0/78 个记录组；专家数据上有 65 个记录 ID 的宽松候选上界，但合格独立父任务与标签条件未知，而且专家数据不是自生成经验。它们分别否定或保留各自的具体可行性，不证明其他自我改进方法有效或无效。

## 成本和精度：示意，不是预约

新一轮三臂 36 回合实际记录 601 次生成、601 步、36 次重置；监督器区间 1,202.35 秒，约每回合 33.4 秒。当前新pilot累计保守计费：新训练 952 秒、先前中断评价 163 秒、新评价 1,203 秒，共 2,318 秒（约 0.644 设备分配小时），另有 60 秒预留而非实耗；更早 R19 等不在这笔数中。共享设备、实际总物理 I/O 和不可见清理尾部仍有未知，不能把设备分配时间称作实际独占利用率。

若仅按当前 36 回合平均值线性外推，200 个父任务的三臂评价约需 600 回合、5.6 分配小时和约 10,017 次生成及步骤，外加 600 次 reset、训练、数据获取和清理；这个数字不是保证，任务长度、共享GPU和I/O可显著改变。当前实现对每回合约 16.4 GB 的基座执行一次完整哈希，600 回合仅基座哈希就约 9.84 TB 逻辑读取，模型加载等额外读取尚未计入。这一实现开销必须在大规模确认前优化或明确计入；不得未经验证而弱化文件身份约束。

作为假设性样本量参考，若父任务独立、真实配对不一致率为 20%、目标改善 10 个百分点、两项比较采用保守单项 α=0.025，200 对的精确 McNemar 检验功效约 81%；若目标仅 5 个百分点，同样假设下 800 对约 81%。这些输入是场景假设，不是本研究估计；实际任务依赖、未知结果与多次选择会降低可解释性。不能把换 seed 或同一模板改名当成新的独立父任务。

## 当前继续路线

1. 保留刚完成的 36 回合和早前停止批次，使用原始账本与公开字段对两项失败的探索行为做匿名诊断，不以这些已看过的任务当确认集，也不凭直觉制造正确动作标签。
2. 设计以单一模型真实成功经验为来源的下一项受控数据/训练实验；将相同训练起点、数据量、训练预算与回放对照分开，预先固定任务隔离和完整总成本。只有在真实记录足以支持合法的状态—动作监督并经检验时才进入训练；这不会修改冻结基线或引入记忆、DPO、额外环境。
3. 继续在相同 TextWorld/PDDL 栈验证人工构造的 DEV 任务与完整项目适配；现有三个两步玩具任务只证明底层机械可行，不是独立测试集或模型成功。未来确认材料必须先固定来源和父任务边界，再做评价；当前不能以已看过的开发数据替代。
