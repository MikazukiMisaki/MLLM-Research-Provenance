# SI-P2 如何判断“可区分”和“数据足够”

本文件是协调方本轮判断口径，不是训练协议或执行许可。固定共同质量/anchor规则见 COMMON_AUDIT_RULES.md，已在向两位agent派发前锁定。事实计数须由原件和冻结交付交叉核验，不以作者自评替代。

## 三个不同问题

1. **集合可分性**：共同质量及去重后，C非空、C包含于B_pool，B_pool减C仍有真实、目标合格的neutral-success。若没有，不能比较success-only与增量采纳。
2. **对照构造容量**：来源/家族组成及重复上限约束下，是否能从B_pool得到与C可比的不同数据。只有B池较大不等于训练预算已匹配；不能把95个目标对10个目标并称等预算，也不能将C重复近十遍假装获得新数据。B减C用于审计可分性，**不能将“排除C”作为success-only对照的采样条件**，否则对照也利用了CONTINUE标签。
3. **研究数据是否足够**：不同集合与有效动作是必要条件，不证明其监督梯度能迁移到新任务。需同时考虑独立task数、输入/行为/家族覆盖、版本及策略来源、真实监督token/合理曝光、独立评估空间、成本和目标主张。没有一个普遍适用的“至少N条才可学习”的阈值；本轮不编造该阈值，也不由训练样本数推评估功效。

## 结论强度和停止

- 只有来源链与不同集合：最多说明**有限历史蒸馏对照可描述**，不是学习效能或自主self-improvement。
- 只有少量task/单一来源可追溯、家族偏斜，且需大量重放才形成更新：不据此启动以普遍成功率/筛选机制为目标的正式验证。小样本绝对学不动也不是可由此次审计证明的命题。
- 若完全版本绑定口径只剩极少C，同时历史混合口径依靠大量PARTIAL版本，不能悄悄切换口径宣称数据充分；两者须并列披露。
- 在二值结果下，B={R_T=1}，C={R_T=1且R_A=0}。因此给定B，正增量筛选等价于选择基线失败的成功演示。B/C比较可检验这个采纳配方，但不能单独证明独特的价值估计算法，或排除hard-case选择/难度组成解释。这个代数限制不需新增实验才能确认。
- 无法支持预设目标时应对**当前历史池方案**给明确NO_GO，而不是不断追加审计、换anchor或扩K直至positive。是否另设计受控新数据是另一个研究决定，本轮不采集、不训练。

统计验收仍沿用SI-P1预设：两项共同主比较C−A/C−B_pool、双侧exact McNemar+Holm、完整配对表和gross harm；5pp观测价值门槛与5%观测伤害护栏不是此池已证明的效应。训练task数也不等于未来E。旧oracle 5.56pp不能填补任何学习/功效缺口。

本轮只能给数据结构、证据强度与研究投入的判断。无新科学预算、模型/环境/tokenizer/训练调用或clearance。
